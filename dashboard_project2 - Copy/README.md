# Precision Dashboard

واجهة Dashboard مبنية بـ React + Vite + MUI مع ثيم فاتح/داكن، شريط جانبي ثابت، وشريط علوي تفاعلي.

## التشغيل المحلي

```bash
npm install
npm run dev
```

## التحقق من الجودة

```bash
npm run lint
npm run build
```

## ملاحظات

- يتم حفظ وضع الثيم تلقائيًا في المتصفح.
- الخط الافتراضي المستخدم هو Inter.
- التخطيط متجاوب ويعرض الشريط الجانبي كنسخة دائمة على الشاشات الكبيرة ونسخة مؤقتة على الجوال.
